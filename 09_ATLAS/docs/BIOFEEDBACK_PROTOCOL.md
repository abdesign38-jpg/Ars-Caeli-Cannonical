# ATLAS-002 — Protocolo Biofeedback v0.1

## Escalas sugeridas

| Métrica | ID | Rango |
|---|---|---|
| Inmersión | ACM-001 | 0–10 |
| Distorsión temporal | ACM-002 | 0–10 |
| Intensidad corporal | ACM-003 | 0–10 |
| Imaginería | ACM-004 | 0–10 |
| Claridad mental | ACM-005 | 0–10 |
| Tranquilidad | ACM-006 | 0–10 |
| Movimiento percibido | ACM-007 | 0–10 |
| Alteración respiratoria | ACM-008 | 0–10 |
| Confort | ACM-009 | 0–10 |

## Registro abierto

Además de las escalas, registrar:

- localización corporal;
- tipo de sensación;
- duración;
- orden de aparición;
- imágenes espontáneas;
- percepción espacial;
- percepción de agencia;
- comentarios libres.

## Regla de lenguaje

Preferir:

> “Sentí presión en la zona superior izquierda de la cabeza.”

Evitar:

> “Se activó mi córtex prefrontal izquierdo.”

La segunda frase infiere una localización neurológica no medida.

## Cierre

Toda sesión debe incluir:

- estado final;
- hidratación;
- orientación temporal;
- presencia de síntomas persistentes;
- necesidad o no de seguimiento.
