# Modelo de Física Cognitiva

```text
Presencia
        ↘
     Atención
        ↙
Gradiente ── Horizonte
      │
 Entropía ─ Vacío
      │
 Latencia
      │
 Curvatura Temporal
      │
 Suspensión
```

La física cognitiva modela relaciones funcionales del ecosistema. Las hipótesis deberán contrastarse mediante experimentos y biofeedback.
