# ATLAS-003 — Política de anonimización

## Principios

1. No guardar nombre legal.
2. Usar identificadores pseudónimos.
3. Separar datos personales de datos experimentales.
4. No registrar información médica innecesaria.
5. Toda exportación debe usar IDs anónimos.

## Formato

```text
P-0001
P-0002
...
```

## Nota

En esta versión inicial, las sesiones migradas usan `P-0001`.
