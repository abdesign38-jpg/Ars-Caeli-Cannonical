# Ars Caeli Infrastructure v0.1

Esta entrega contiene la infraestructura mínima viable para conectar APL, AEON, BIOFEEDBACK, MNEMOSYNE y ATLAS.

## Incluye

- ACSPEC-008 — Metamodelo.
- ACSPEC-010 — Leyes de Evolución del Conocimiento.
- ACSPEC-011 — Filosofía del Error.
- Modelo de relaciones.
- Ciclo de vida de entidades.
- Flujo epistemológico.
- Esquema JSON inicial.
- Grafo semántico inicial.
- Ejemplos APL y JSON.
- Registro de tipos de entidad.

## Propósito

No busca cerrar el sistema. Busca darle huesos.

A partir de aquí, cada nuevo concepto, hipótesis, experimento y observación podrá integrarse con identidad, relaciones y trazabilidad.
