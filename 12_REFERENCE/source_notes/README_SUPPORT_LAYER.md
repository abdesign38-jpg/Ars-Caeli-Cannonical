# Ars Caeli Support Layer v0.1

Esta capa añade las reglas mínimas necesarias para que Ars Caeli crezca de forma consistente.

## Incluye

- Tipos de datos nucleares.
- Unidades y escalas.
- Convenciones de nombres.
- Metadatos obligatorios.
- Referencias cruzadas.
- Versionado semántico.
- Política de compatibilidad.
- Estructura canónica de carpetas.
- Plantillas y esquemas legibles por software.

## Objetivo

Evitar que el corpus se vuelva ambiguo, inconsistente o difícil de migrar conforme aumenten los documentos, experimentos y agentes.
