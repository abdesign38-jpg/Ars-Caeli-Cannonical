# Máquina Epistemológica de Ars Caeli

## Flujo principal

```text
PERCEIVE
→ NAME
→ MODEL
→ IMPLEMENT
→ EXPERIMENT
→ OBSERVE
→ CORRELATE
→ HYPOTHESIZE
→ REFINE
→ CONSOLIDATE
```

## Motores

- **NOOGENESIS** coordina preguntas e hipótesis.
- **AEON** genera ecosistemas.
- **BIOFEEDBACK** registra observaciones.
- **MNEMOSYNE** detecta patrones.
- **ATLAS** consolida conocimiento.

## Regla de flujo

Ningún motor puede saltar directamente de experiencia a conocimiento consolidado.
