## 1. Propósito

APL es un lenguaje específico de dominio para describir ecosistemas cognitivos, sus componentes, sus relaciones y la experiencia observada.

APL debe permitir:

1. Definir conceptos sin confundirlos con variables.
2. Operacionalizar conceptos.
3. Registrar cómo AEON implementa variables.
4. Formular hipótesis con incertidumbre explícita.
5. Registrar observaciones sin interpretación automática.
6. Diferenciar modelos experimentales de modelos simbólicos.
7. Conservar trazabilidad entre experimento, observación, correlación y conocimiento.
8. Alimentar ATLAS con datos consistentes y versionables.

## 2. Unidad fundamental

La unidad fundamental de APL es la **entidad trazable**.

Toda entidad debe tener:

- identificador;
- tipo;
- versión;
- estado;
- definición;
- relaciones;
- evidencia o procedencia;
- capa de conocimiento.

## 3. Capas de conocimiento

APL distingue tres capas:

### 3.1 Universal

Describe propiedades del ecosistema cognitivo aplicables sin clasificar a la persona.

Ejemplos:

- densidad del vacío;
- entropía;
- horizonte;
- latencia;
- curvatura temporal.

### 3.2 Individual

Describe variables biológicas, psicológicas y contextuales.

Ejemplos:

- sensibilidad sensorial;
- sueño;
- respiración;
- estado emocional previo;
- historia subjetiva.

### 3.3 Simbólica

Describe modelos interpretativos de Ars Caeli.

Ejemplos:

- Inframundo;
- Universo Reverso;
- Dios Olvidado;
- heridas arquetípicas;
- geometrías simbólicas.

La capa simbólica no debe sobrescribir ni reemplazar la observación experimental.

## 4. Flujo epistemológico

```text
EXPERIENCE
→ OBSERVATION
→ RECORD
→ CORRELATION
→ HYPOTHESIS
→ IMPLEMENTATION
→ EXPERIMENT
→ REFINEMENT
→ KNOWLEDGE
```

## 5. Regla de separación

APL debe distinguir siempre:

- **dato observado**;
- **interpretación**;
- **hipótesis**;
- **modelo simbólico**;
- **conocimiento consolidado**.

Ninguna experiencia individual se convierte automáticamente en causalidad.

## 6. Ciclo Hermético de Investigación

```text
Percibir
→ Nombrar
→ Modelar
→ Construir
→ Experimentar
→ Observar
→ Correlacionar
→ Refinar
→ Percibir nuevamente
```

## 7. Principio rector

APL no existe para imponer significado, sino para hacer visible cómo emerge, cambia y se relaciona el significado dentro de un ecosistema cognitivo.
