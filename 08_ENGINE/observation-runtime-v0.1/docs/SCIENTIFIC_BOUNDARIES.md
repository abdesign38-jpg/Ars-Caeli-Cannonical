# Scientific & Epistemic Boundaries — D.1

D.1 expands **capture**, not interpretation.

## Operationally measurable in D.1

D.1 can directly record:
- a participant-selected response;
- whether an input occurred;
- a monotonic runtime interval;
- a timeout/abort;
- browser/runtime context;
- artifact identity;
- a participant-reported observation;
- a contextual marker;
- whether integrity was valid/invalid/unknown.

## Not established by D.1

D.1 alone does not establish:
- neural latency;
- subliminal processing;
- therapeutic effect;
- energetic influence;
- wound activation;
- symbolic causation;
- sacred-geometry effect;
- a causal relation between AEON signal and behavior.

## Browser timing

`performance.now()` is used because it is monotonic and designed for high-resolution intervals.

Its numerical precision is not equivalent to end-to-end sensory timing accuracy.

Display refresh, browser scheduling, input devices and hardware can still contribute offsets or variability.

D.1 therefore preserves timing provenance and integrity rather than pretending a browser timestamp is a neural timestamp.

## Unexpected phenomena

Unexpected participant/context markers are legitimate raw observations when they are accurately attributed.

Their scientific meaning remains open.

A later phase may:
- derive a hypothesis;
- define a new dependent variable;
- design a confirmatory test.

It must not retroactively pretend that an exploratory marker was preregistered.
