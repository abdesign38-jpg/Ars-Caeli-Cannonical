# Validación APL

## Validación mínima de entidad

Una entidad válida debe incluir:

- ID;
- título;
- versión;
- estado;
- capa;
- definición;
- relaciones;
- procedencia.

## Validación de hipótesis

Una hipótesis válida debe incluir:

- variables independientes;
- variable o estado esperado;
- dirección del efecto;
- incertidumbre;
- condiciones de prueba;
- criterio de refutación.

## Validación de experimento

Un experimento válido debe incluir:

- versión de AEON;
- duración;
- parámetros ACP;
- variables externas;
- protocolo de cierre;
- criterio de interrupción;
- instrumento de registro.

## Validación de observación

Una observación válida debe:

- usar lenguaje literal;
- separar sensación de localización anatómica inferida;
- no diagnosticar;
- no convertir metáforas en hechos;
- registrar intensidad, duración y contexto cuando sea posible.

## Validación de conocimiento consolidado

Un `ACK` requiere:

- múltiples sesiones;
- trazabilidad;
- método definido;
- revisión de contradicciones;
- versión del criterio;
- limitaciones explícitas.
