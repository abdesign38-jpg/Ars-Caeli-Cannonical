# ATLAS-004 — Reglas de migración

Las primeras sesiones provienen de conversación retrospectiva y no de formularios estructurados.

## Consecuencias

- Algunos parámetros no están disponibles.
- Varias escalas quedan como `null`.
- Las observaciones se conservan en lenguaje cercano al original.
- Las interpretaciones posteriores se registran aparte.
- No se rellenan datos faltantes por imaginación.

## Estado

Las sesiones migradas se marcan:

```yaml
data_quality: retrospective
completeness: partial
```
