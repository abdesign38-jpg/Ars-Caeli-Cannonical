# ACSPEC-001 — Epistemología

## Objetivo

Definir cómo nace el conocimiento dentro de Ars Caeli.

## Ciclo

Experiencia
→ Observación
→ Registro
→ Correlación
→ Hipótesis
→ Implementación
→ Experimento
→ Refinamiento
→ Conocimiento

## Niveles

### Observación
Describe literalmente la experiencia.

### Interpretación
Propone un significado.

### Hipótesis
Relaciona variables con incertidumbre explícita.

### Conocimiento
Resultado acumulado, reproducible y trazable.

## Criterios

Una experiencia aislada nunca constituye evidencia suficiente.
La ausencia de confirmación tampoco invalida automáticamente un modelo simbólico.
