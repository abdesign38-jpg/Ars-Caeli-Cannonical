# Measurement Language Extension v0.1

D.0 separates APL knowledge layers (`universal`, `individual`, `symbolic`) from experimental evidence roles. `behavioral_measured` is an evidence role, not a fourth APL layer.

Raw behavioral records preserve choice, reaction time, response status and provenance. Correctness, accuracy, threshold and PSE are derived metrics. Confidence is `participant_reported`.

Browser reaction time may contain scheduling, display, device and input latency. It is not neural latency.
