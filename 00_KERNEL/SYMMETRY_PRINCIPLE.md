# Principio de Simetría

Toda idea madura en Ars Caeli debe responder cuatro preguntas.

## 1. ¿Qué es?

**Ontología**

Define la entidad, sus límites y su categoría.

## 2. ¿Cómo funciona?

**Mecanismo**

Describe la relación causal propuesta o la dinámica teórica.

## 3. ¿Cómo se implementa?

**Ingeniería**

Explica cómo AEON, Noogenesis u otro motor modifica o representa la entidad.

## 4. ¿Cómo se observa?

**Biofeedback**

Define las mediciones, escalas y registros asociados.

## Matriz de simetría

| Dimensión | Pregunta | Salida APL |
|---|---|---|
| Ontología | ¿Qué es? | `ENTITY` / `CONCEPT` |
| Mecanismo | ¿Cómo funciona? | `RELATION` / `MODEL` |
| Ingeniería | ¿Cómo se implementa? | `IMPLEMENTATION` / `ENGINE` |
| Observación | ¿Cómo se observa? | `OBSERVATION` / `METRIC` |

## Estados de madurez

- `seed`: solo existe la intuición.
- `defined`: tiene definición ontológica.
- `operationalized`: tiene variable o métrica.
- `implemented`: existe en un motor.
- `observed`: tiene registros.
- `correlated`: tiene patrones repetidos.
- `provisional`: hipótesis fortalecida, aún abierta.
- `consolidated`: conocimiento operativo estable.
- `deprecated`: ya no se recomienda.
- `rejected`: no se sostuvo bajo los criterios definidos.

Una entidad no debe considerarse madura si falla una dimensión de simetría.
