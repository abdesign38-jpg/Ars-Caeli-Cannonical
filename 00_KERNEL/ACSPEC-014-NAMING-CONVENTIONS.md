# ACSPEC-014 — Naming Conventions

## Identificadores

Formato:

```text
PREFIX-NNNN
```

Ejemplos:

- `ACP-0001`
- `ACX-0004`
- `ACO-0012`

## Archivos

Formato recomendado:

```text
ACSPEC-101-Vacio.md
ACP-0002-Densidad-del-Vacio.md
```

## Reglas

1. IDs en mayúsculas.
2. Guion medio como separador.
3. Nombres de archivo sin acentos si el sistema destino lo requiere.
4. No reutilizar IDs.
5. No cambiar el ID aunque cambie el título.
6. Slugs y claves JSON en `snake_case`.
