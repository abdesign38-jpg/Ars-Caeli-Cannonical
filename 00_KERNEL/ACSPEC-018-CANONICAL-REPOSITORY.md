## Regla de ubicación

Todo entregable debe pertenecer a una sola categoría primaria.

## Fuente canónica

El repositorio Git es la fuente de verdad.

Obsidian, MkDocs, bases de datos y agentes consumen esa fuente, pero no la reemplazan.
