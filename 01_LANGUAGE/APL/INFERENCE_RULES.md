# Reglas de Inferencia

## IR-001 — Observación no implica causalidad

```text
ACO + ACO + ACO ≠ causa
```

Las observaciones repetidas pueden generar correlaciones, no causalidad automática.

## IR-002 — Correlación requiere umbral

Una relación no puede elevarse a correlación provisional sin:

- número mínimo de sesiones;
- parámetros comparables;
- ausencia de contradicciones graves;
- registro de variables externas.

## IR-003 — El modelo simbólico no valida el experimental

La coincidencia con un arquetipo no confirma una causa física.

## IR-004 — El modelo experimental no invalida el simbólico

La falta de evidencia causal no elimina el valor interpretativo de un símbolo.

## IR-005 — Toda inferencia conserva incertidumbre

Valores sugeridos:

- `unknown`
- `weak`
- `moderate`
- `strong`
- `replicated`

## IR-006 — Cambio de capa explícito

Toda transición entre universal, individual y simbólico debe quedar declarada.

## IR-007 — Contradicción productiva

Las observaciones contradictorias no se borran. Se registran como evidencia para refinar la hipótesis.

## IR-008 — Seguridad prevalente

Si una configuración produce eventos adversos, se suspende antes de estudiar su potencia.
