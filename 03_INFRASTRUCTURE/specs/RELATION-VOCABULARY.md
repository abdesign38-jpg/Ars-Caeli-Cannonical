# Vocabulario de Relaciones APL

## Relaciones estructurales

- `is_a`
- `part_of`
- `contains`
- `inherits_from`
- `extends`
- `depends_on`
- `supersedes`
- `compatible_with`

## Relaciones operativas

- `implements`
- `implemented_by`
- `generates`
- `measures`
- `observes`
- `records`
- `stores`
- `modulates`
- `activates`
- `deactivates`

## Relaciones epistemológicas

- `supports`
- `contradicts`
- `derived_from`
- `correlates_with`
- `refines`
- `falsifies`
- `informs`
- `consolidates`

## Relaciones entre capas

- `symbolizes`
- `interprets`
- `maps_to`
- `must_not_override`

## Regla

La relación `related_to` solo debe usarse cuando no existe todavía una relación más precisa.
