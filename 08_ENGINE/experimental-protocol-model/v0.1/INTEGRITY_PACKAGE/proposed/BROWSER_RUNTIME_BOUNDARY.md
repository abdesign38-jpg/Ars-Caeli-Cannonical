# Browser Runtime Contract for Phase C

This file describes the boundary B.1 creates. Do not implement the Void Gate in B.1.

## Raw files are authoring inputs only

Forbidden in future Sound Field runtime:

```js
fetch("../experimental-protocol-model/v0.1/examples/C1_LOW_ASC.stimulus-condition.json")
```

Allowed:

```js
fetch("../experimental-protocol-model/v0.1/compiled/conditions/C1_LOW_ASC.executable.json")
```

## Minimum browser guard

Before accepting an executable condition:

```js
function assertExecutableCondition(value){
  if(!value || value.execution_status!=="validated"){
    throw new Error("AEON_EXECUTION_BLOCKED: condition is not compiler-validated");
  }

  if(value.compiler_version!=="0.1"){
    throw new Error("AEON_EXECUTION_BLOCKED: unsupported compiler version");
  }

  if(value.runtime_schedule?.pattern!=="fixed_periodic"){
    throw new Error("AEON_EXECUTION_BLOCKED: unsupported runtime schedule");
  }

  return value;
}
```

This is a runtime sanity guard, not a replacement for build-time semantic validation.

## Authority

Phase C Void Gate reads:

```js
condition.runtime_schedule.block_duration_s
condition.runtime_schedule.cycle_duration_s
condition.runtime_schedule.active_duration_s
condition.runtime_schedule.silent_duration_s
```

It may display:
- silence ratio
- event rate
- mean gap

but those displayed values come from the compiled runtime schedule.

It must not recalculate from an arbitrary source JSON loaded by the browser.

## Protocol integrity

Executable protocol contains:

```json
"condition_fingerprints": {
  "C1_LOW_ASC": "...sha256..."
}
```

When Phase C is implemented, either:
1. browser verifies the canonical SHA-256 of each compiled condition against the protocol fingerprint, or
2. a bundled manifest generated by the same compiler performs that check before runtime.

Do not simply trust matching filenames.

## Fail closed

If:
- file missing;
- status not validated;
- compiler version unsupported;
- condition fingerprint mismatch;
- schedule pattern unsupported;

then:
- disable Run;
- show a readable integrity error;
- do not synthesize audio.
