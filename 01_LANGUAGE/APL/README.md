# APL — Aletheia Percepta Language

**Versión:** 0.1.0  
**Estado:** Experimental / Founding  
**Sistema:** Ars Caeli  
**Fecha:** 2026-07-10  

APL es el lenguaje epistemológico y descriptivo de Ars Caeli. Su propósito es representar de manera consistente conceptos, variables, estados, motores, observaciones, hipótesis, relaciones, experimentos y conocimiento consolidado.

APL no pretende demostrar explicaciones metafísicas. Permite registrarlas como modelos simbólicos diferenciados de los modelos experimentales.

## Arquitectura

```text
ARS CAELI
└── ALETHEIA PERCEPTA
    ├── APL — Lenguaje
    ├── NOOGENESIS — Coordinación cognitiva
    ├── AEON — Motor generativo
    ├── BIOFEEDBACK — Registro
    ├── MNEMOSYNE — Memoria de patrones
    └── ATLAS — Conocimiento consolidado
```
