Ars Caeli
Ars Caeli es un corpus experimental que integra lenguaje, epistemología, modelos de percepción, física cognitiva, alquimia simbólica, memoria experimental e interfaces computacionales dentro de una arquitectura común.
Su objetivo no es reducir la experiencia humana a una sola explicación.
Busca construir un sistema suficientemente riguroso para distinguir entre:
lo observado;
lo inferido;
lo simbolizado;
lo experimentado;
y lo que todavía no sabemos.
Ars Caeli trabaja en la frontera entre estructura y significado.
Entre software y símbolo.
Entre presencia y vacío.
Entre descenso y retorno.
---
DESCENSO Y RETORNO
El movimiento fundamental de Ars Caeli no es lineal.
No propone ascender evitando aquello que produce densidad, contradicción o fractura.
Propone descender lo suficiente para reconocer la estructura, atravesar el vacío que aparece cuando una configuración deja de sostenerse y observar qué forma puede emerger después.
```text
DESCENSO Y RETORNO


Presencia ─────╲
               ╲____ VACÍO ____
                              ╱
                         ____╱──── Presencia
```
El retorno no representa regresar exactamente al punto inicial.
Después del vacío, la presencia puede reaparecer con una configuración diferente.
Por ello:
> **Retornar no es retroceder.  
> Retornar es recuperar presencia después de haber atravesado una transformación.**
El descenso permite observar.
El vacío permite reorganizar.
El retorno permite integrar.
---
REINTEGRACIÓN DEL SER
La reintegración tampoco necesita ocurrir mediante una única ruptura absoluta.
Puede producirse mediante pequeñas discontinuidades de la configuración previa: microvacíos.
```text
REINTEGRACIÓN DEL SER


Presencia ──────╲_╱────╲_╱────╲_╱────
                 ↑      ↑      ↑
             microvacíos
```
Un microvacío es un intervalo donde el patrón dominante pierde momentáneamente continuidad.
En el modelo Ars Caeli, ese intervalo puede permitir:
observación;
cambio de atención;
reducción temporal de automatismos;
reorganización simbólica;
modificación de una respuesta;
aparición de una configuración alternativa.
La reintegración puede entenderse entonces como una sucesión:
```text
Presencia
   ↓
Desestabilización
   ↓
Microvacío
   ↓
Reorganización
   ↓
Nueva presencia
   ↓
Microvacío
   ↓
Integración
```
No se busca una presencia permanentemente rígida.
Se busca una presencia con capacidad de perder forma sin perder continuidad.

Capas del sistema
Ars Caeli mantiene separadas distintas capas epistemológicas.
1. Canon
Conceptos, definiciones, reglas, esquemas y modelos documentados mediante Markdown y JSON.
El canon vive en el repositorio.
2. Observación
Datos o registros producidos durante una sesión o experimento.
Una observación debe poder existir sin necesidad de una interpretación inmediata.
3. Interpretación experimental
Hipótesis provisional construida a partir de una observación.
Debe permanecer identificada como interpretación y no convertirse silenciosamente en hecho.
4. Interpretación simbólica
Lectura alquímica, arquetípica o contemplativa de un proceso.
Su función es producir significado, no sustituir evidencia empírica.
5. Interfaces
Aplicaciones como AEON Sound Field operacionalizan partes del corpus mediante interacción, visualización y estímulos reproducibles.
La interfaz consume el canon.
No se convierte automáticamente en canon.
---
AEON Sound Field
AEON Sound Field v0.3 es la primera interfaz neuroenergética de sesión desarrollada dentro del ecosistema Ars Caeli.
Su arquitectura actual está organizada alrededor del trayecto:
```text
DESCENSO → SESIÓN / UMBRAL → RETORNO
```
La interfaz incorpora:
perfil de sesión;
intención;
navegación por Descenso, Sesión y Retorno;
representación del campo mediante mandala y toroide;
matriz alquímica de estado;
temporizador;
motor Web Audio;
visualización dinámica;
selección de correspondencias simbólicas de frecuencia;
registro de observaciones;
almacenamiento local;
biblioteca canónica;
sincronización con el repositorio;
exportación de memoria a ATLAS.
---
Matriz alquímica de estado
La interfaz utiliza actualmente cuatro dimensiones operativas:
Inframundo
Representa, dentro del modelo, densidad, retención, profundidad y material no integrado.
Activación
Representa velocidad, alerta, movilización y presión cognitiva.
Disociación
Representa distancia respecto a la experiencia, reducción de presencia o separación funcional.
Apertura
Representa capacidad de observar, procesar, simbolizar e integrar sin perder continuidad.
Estas dimensiones son variables internas del modelo Ars Caeli.
No constituyen diagnósticos médicos ni psicológicos.
---
Perfil de Descenso y Retorno
Una sesión puede representarse mediante dos movimientos complementarios.
Perfil de descenso
Describe la configuración con la que el sistema entra hacia una zona de mayor profundidad.
Puede considerar variables como:
```text
Inframundo
Activación
Disociación
Apertura
Presencia
Vacío
Entropía
Horizonte
Resonancia
Cristalización
Gradiente Atencional
Respiración Ambiental
```
Perfil de retorno
Describe las condiciones mediante las cuales el sistema recupera organización y presencia.
El objetivo no es invertir matemáticamente el descenso.
El retorno puede tomar otra trayectoria.
```text
DESCENSO ≠ RETORNO INVERSO
```
Por ello, Ars Caeli trata ambos como perfiles relacionados pero independientes.

Frecuencia y correspondencia simbólica
AEON puede utilizar frecuencias audibles como parámetros reproducibles de una sesión.
Ars Caeli distingue dos cosas:
```text
frecuencia física medible
           ≠
significado simbólico asignado
```
Por ello, asociaciones como:
```text
174 Hz
285 Hz
396 Hz
417 Hz
528 Hz
639 Hz
963 Hz
```
pueden existir dentro del sistema como correspondencias simbólicas o experimentales, pero no deben presentarse automáticamente como evidencia de:
curación;
regeneración celular;
modificación genética;
tratamiento psicológico;
tratamiento neurológico;
tratamiento médico.
La frecuencia es medible.
Su interpretación pertenece a otra capa.
Esta distinción es una regla fundamental del proyecto.

ATLAS
ATLAS es la capa de memoria de Ars Caeli.
Registra sesiones, observaciones, parámetros e interpretaciones.
```text
EXPERIENCIA
    ↓
SESIÓN
    ↓
OBSERVACIÓN
    ↓
ATLAS
    ↓
COMPARACIÓN
    ↓
HIPÓTESIS
```
ATLAS puede almacenar:
identificación de sesión;
experimento;
participante anonimizado;
motor utilizado;
versión del motor;
duración;
contexto;
intención;
parámetros;
perfil de descenso;
perfil de retorno;
observaciones;
interpretaciones experimentales;
interpretaciones simbólicas;
condiciones de seguridad;
calidad y completitud del registro.
Regla ATLAS
> **ATLAS conserva memoria.  
> ATLAS no decide causalidad.**
Una correlación registrada no debe convertirse automáticamente en una explicación causal.
---
Aletheia Percepta Language — APL
`01_LANGUAGE/APL/` contiene el lenguaje destinado a formalizar observaciones y relaciones dentro del corpus.
APL busca permitir que una percepción pueda traducirse progresivamente desde lenguaje humano hacia estructuras que puedan:
almacenarse;
compararse;
validarse;
relacionarse;
procesarse computacionalmente.
El propósito no es eliminar el lenguaje simbólico.
Es impedir que el lenguaje simbólico y el dato observado se vuelvan indistinguibles.

Regla canónica
Los archivos Markdown y JSON de este repositorio son la fuente documental de Ars Caeli.
Las aplicaciones, agentes, motores, interfaces y bases de datos deben:
consumirlos;
sincronizarse con ellos;
referenciarlos;
o producir propuestas explícitas de modificación.
No deben sustituirlos silenciosamente.
```text
CANON → INTERFAZ
```
no:
```text
INTERFAZ → CANON AUTOMÁTICO
```
---
Principio de separación epistemológica
Toda afirmación dentro del sistema debería poder identificarse como una de estas categorías:
```text
[C] CANÓNICA
[O] OBSERVADA
[E] EXPERIMENTAL
[S] SIMBÓLICA
[H] HIPÓTESIS
```
Ejemplo:
```text
[O] Durante la sesión se reportó una sensación de expansión.

[S] La expansión fue interpretada como apertura.

[E] El parámetro Horizonte aumentó durante el mismo intervalo.

[H] Horizonte y sensación de expansión podrían estar relacionados.
```
Estas cuatro frases no dicen lo mismo.
Ars Caeli debe preservar esa diferencia.

Seguridad y alcance
Ars Caeli es actualmente un sistema experimental, contemplativo, simbólico y computacional.
No sustituye:
atención médica;
diagnóstico clínico;
psicoterapia;
intervención psiquiátrica;
tratamiento neurológico;
tratamiento oncológico;
atención de emergencia.
Los modelos biológicos, neuroenergéticos, alquímicos y simbólicos contenidos o explorados por Ars Caeli deben mantener visible su nivel de evidencia y su procedencia.
La exploración puede ser profunda.
La clasificación debe seguir siendo precisa.

Filosofía de desarrollo
Ars Caeli no busca elegir entre poesía y estructura.
Busca que cada una sepa cuándo está hablando.
```text
SÍMBOLO          DATOS
   ╲              ╱
    ╲            ╱
     SIGNIFICADO
          │
          ▼
      ESTRUCTURA
          │
          ▼
      OBSERVACIÓN
          │
          ▼
       MEMORIA
```
La alquimia aporta lenguaje para la transformación.
La ingeniería aporta reproducibilidad.
ATLAS aporta memoria.
APL aporta estructura.
AEON aporta experiencia e interfaz.
El canon mantiene sus fronteras.
