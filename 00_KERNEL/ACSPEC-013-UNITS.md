# ACSPEC-013 — Units and Scales

## Unidades físicas

- `Hz`
- `dB`
- `s`
- `ms`
- `min`
- `bpm`

## Escalas normalizadas

- `0..1`
- `0..10`
- `%`

## Categorías

Las categorías deben usar catálogos controlados, nunca texto libre cuando exista un vocabulario oficial.

## Reglas

1. Nunca guardar un número sin unidad cuando la unidad sea relevante.
2. Las escalas 0..10 deben documentar extremos.
3. Los valores normalizados deben declarar dirección semántica.
4. No mezclar Hz, bpm y segundos como si fueran equivalentes.
