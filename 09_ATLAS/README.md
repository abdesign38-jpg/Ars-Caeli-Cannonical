# ATLAS Core v0.1

**Sistema:** Ars Caeli  
**Componente:** ATLAS  
**Versión:** 0.1.0  
**Estado:** Experimental  
**Fecha:** 2026-07-10  

ATLAS Core es la primera implementación documental del sistema de memoria de Ars Caeli.

## Objetivos

1. Registrar sesiones de manera consistente.
2. Separar observación, interpretación e hipótesis.
3. Conservar parámetros de AEON y variables externas.
4. Permitir trazabilidad entre experimentos, observaciones y conocimiento.
5. Preparar el corpus para análisis futuro en MNEMOSYNE.

## Contenido

- Registro maestro del corpus.
- Modelo de sesión.
- Esquemas JSON.
- Plantillas Markdown, JSON y APL.
- Protocolo Biofeedback.
- Migración inicial de nuestras primeras sesiones experimentales.
- Índices ACX y ACO.

## Regla principal

ATLAS conserva memoria. No decide causalidad.
