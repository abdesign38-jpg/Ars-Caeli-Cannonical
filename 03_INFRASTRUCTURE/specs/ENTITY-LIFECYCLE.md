# Ciclo de Vida de Entidades

```text
seed
→ defined
→ operationalized
→ implemented
→ observed
→ correlated
→ provisional
→ consolidated
```

Ramas alternativas:

```text
seed → rejected
defined → deprecated
implemented → suspended
provisional → reclassified
consolidated → revised
```

## Reglas

- `seed`: intuición inicial.
- `defined`: existe definición ontológica.
- `operationalized`: existe variable o métrica.
- `implemented`: existe en un motor.
- `observed`: tiene registros.
- `correlated`: tiene patrones repetidos.
- `provisional`: hipótesis fortalecida.
- `consolidated`: conocimiento operativo estable.
- `deprecated`: ya no se recomienda.
- `rejected`: no se sostuvo.
- `suspended`: detenido por seguridad o calidad.
- `reclassified`: cambió de tipo o capa.
- `revised`: conocimiento consolidado actualizado.
